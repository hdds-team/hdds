## Running Examples

### From the Repository

```bash
git clone https://git.hdds.io/hdds/hdds.git
cd hdds

# Run a Rust example of the hdds crate
cargo run -p hdds --example basic_pubsub

# Run with release optimizations
cargo run -p hdds --release --example basic_pubsub
```

The samples under `sdk/samples/` use types generated by `hddsgen`; generate
them first with `sdk/samples/scripts/generate.sh`, then follow the README of
the sample set (for example `sdk/samples/01_basics/rust`). `hddsgen` comes from
the separate `hdds_gen` repository:

```bash
git clone https://git.hdds.io/hdds/hdds_gen.git && cargo install --path hdds_gen
```

### In Your Own Package

The pages of this section assume a Cargo package that depends on a clone of
the repository:

```toml title="Cargo.toml"
[dependencies]
hdds = { path = "../hdds/crates/hdds" }
```

Types that need enums, arrays or nested structs are generated from IDL with
`hddsgen gen rust <file.idl> -o src/<name>.rs` and declared as a module of the
package (`pub mod <name>;` in `src/lib.rs`).

## Example: Temperature Sensor

The classic "Hello World" of DDS:

```rust
use hdds::{Participant, QoS, TransportMode, DDS};

#[derive(Debug, Clone, DDS)]
struct Temperature {
    #[key]
    sensor_id: u32,
    value: f32,
}

fn main() -> Result<(), hdds::Error> {
    let participant = Participant::builder("temp_sensor")
        .domain_id(0)
        .with_transport(TransportMode::UdpMulticast)
        .build()?;
    let topic = participant.topic::<Temperature>("sensors/temp")?;
    let writer = topic.writer().qos(QoS::reliable()).build()?;

    writer.write(&Temperature {
        sensor_id: 1,
        value: 23.5,
    })?;

    Ok(())
}
```
